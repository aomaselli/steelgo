# Suites REVISADAS que podem rodar com --permitir-parada-desligada.
#
# Uma linha por suite, cinco campos:
#
#   <sha256>  <caminho>  <erros_esperados>  <assercoes_minimas>  <marcador_final>
#
# sha256 ............. a autorizacao. Editar a suite muda o hash e a
#                      autorizacao CADUCA: quem editar revisa e atualiza esta
#                      lista no mesmo pull request. A alternativa seria
#                      adivinhar pelo texto se o arquivo ainda e confiavel, e
#                      presenca textual de `rollback` ou `raise` nao prova nada
#                      sobre o que acontece em execucao.
# erros_esperados .... quantos erros de SQL a suite produz LEGITIMAMENTE.
#                      `*` significa NAO CONFERIDO. Nao se escreve 0 sem medir.
# assercoes_minimas .. quantas linhas de veredito a suite emite quando roda
#                      inteira. Menos que isso na saida = parte nao rodou.
# marcador_final ..... o rotulo da ULTIMA linha de veredito. Se a ultima linha
#                      da saida nao for essa, a saida esta incompleta.
#
# Os dois ultimos campos vem da revisao do fonte, nao de medicao de execucao.
# Se estiverem errados, a suite REPROVA quando rodar -- falha fechada.
#
# Quem roda com esta permissao nao decide se passou: o validador conta as
# assercoes executadas na SAIDA, exige o marcador final, e termina em codigo
# nao zero se houver falha, saida incompleta, ausencia de veredito ou divergencia
# no numero de erros.
